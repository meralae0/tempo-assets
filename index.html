TEMPOBRIEF · bridge

Ce pont sert à récupérer un fichier du dépôt sous forme de Blob depuis un autre site (YouTube Studio, Meta Business Suite, TikTok Studio) afin de l'injecter dans un champ d'upload.

Usage depuis la console d'un site cible :

const r = await fetch('https://meralae0.github.io/tempo-assets/videos/2026-11-20-sujet.mp4');
const f = new File([await r.blob()], '2026-11-20-sujet.mp4', {type:'video/mp4'});
const dt = new DataTransfer(); dt.items.add(f);
const input = document.querySelector('input[type=file]'); input.files = dt.files;
input.dispatchEvent(new Event('change', {bubbles:true}));
