# tempo-assets — TempoBrief

Dépôt dédié à la chaîne **TempoBrief** (@tempobrief) — actualité FR/EN, style éditorial premium.
Indépendant de tout autre dépôt du compte.

| Dossier | Contenu |
|---|---|
| `brand/` | charte (charte.html), avatar, bannière, polices Playfair Display + Inter |
| `videos/` | vidéos longues 16:9 (`YYYY-MM-DD-slug.mp4`) |
| `shorts/` | shorts 9:16 + couvertures |
| `audio/` | voix TTS (fr/en) et pistes mixées |
| `thumbs/` | miniatures 1280×720 |
| `subs/` | sous-titres SRT (fr/en) |
| `docs/` | scripts, sources, logs de publication |
| `bridge.html` | pont GitHub Pages : expose les fichiers (CORS) pour injection dans YouTube Studio / Meta / TikTok |

Pages : https://meralae0.github.io/tempo-assets/
