Results
• Working code: 3 out of 3. My 14 checks: 14/14 for each app (42/42), not a single cent lost.
• ChatGPT (Instant): under 10 s, a downloadable file, exact integer math, and it said "I haven't run browser-based tests."
• Claude (Opus 5.5): 40 s, the only one that ran its own test cases before answering.
• Gemini (Neon): code only, no explanation, added a "Grand Total" line.
• 8 weird inputs my prompt never mentioned (1,000 people, "1e2", $99,999,999.99 ÷ 7…): same answers everywhere, except one: with the tip box empty, ChatGPT and Claude say "Invalid input", Gemini treats it as 0 %.

THE PROMPT (copy it)
Build me a bill-splitting web app as ONE single HTML file (HTML + CSS + JavaScript, no libraries, no internet).
It must use exactly these element ids: #total (bill), #tip (tip %, default 15), #people (default 2), #calc (the "Split" button), #result.
Rules: 1. The tip is calculated on the bill amount. Grand total = bill + tip, rounded to the cent. 2. Show one line per person, exactly like "Person 1: $12.34". 3. The shares must add up EXACTLY to the grand total, to the cent. If the cents don't divide evenly, the first people pay one cent more. 4. If the bill is empty, zero or negative, if the tip is negative, or if the number of people is not a whole number of at least 1, show only the text "Invalid input" in #result. 5. Make it look clean and modern, and work on a phone.
Give me the complete file.

The lesson: write your rules like test cases. Where my prompt was vague (empty tip), the apps disagreed.
