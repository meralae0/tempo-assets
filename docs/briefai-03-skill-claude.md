# BriefAI #3 — « Crée ton propre Skill Claude en 10 minutes (sans coder) »

Format tuto : vrai enregistrement de claude.ai (Chrome, Xbox Game Bar Win+Alt+R) + habillage Remotion (compteur d'étapes, zooms, curseur, bulles).
Une vidéo en français + piste audio anglaise. Cadeau : skills/scenariste-youtube (SKILL.md + ZIP) sur GitHub.
Sources : support.claude.com « Use skills in Claude » et « How to create custom skills » (consultées le 20/11/2026).

## Script FR (≈ 150 mots/min)
[RÉSULTAT]
Regarde. Je tape une seule phrase : « écris le script de ma prochaine vidéo ». Et Claude me sort un script complet, dans mon format exact : l'accroche, les étapes, les erreurs, le cadeau. Ce n'est pas un prompt que je recopie à chaque fois. C'est un Skill. Et dans dix minutes, tu auras le tien.

[C'EST QUOI]
Un Skill, c'est une fiche d'instructions que Claude garde en mémoire. Quand ta demande correspond, il l'ouvre tout seul et suit tes règles. Ça marche aussi avec le compte gratuit.

[ÉTAPE 1]
Étape un : vérifie l'option. Va dans Paramètres, puis Capacités. Active « Créer et modifier des fichiers ». Les Skills en ont besoin. Si c'est déjà bleu, c'est bon.

[ÉTAPE 2]
Étape deux : écris ton fichier. Ouvre le Bloc-notes, et colle trois blocs. Le nom, en minuscules avec des tirets. La description : c'est la phrase que Claude lit pour savoir quand utiliser ton Skill, deux cents caractères maximum. Et en dessous, tes instructions, comme si tu briefais un assistant. Enregistre le fichier sous le nom SKILL point md.

[ÉTAPE 3]
Étape trois : importe-le. Dans Claude, ouvre Plug-ins, puis l'onglet Skills. Clique sur Ajouter, puis Importer un plug-in. Glisse ton fichier SKILL point md, et clique sur Importer. Pas besoin de ZIP : le fichier seul suffit.

[ÉTAPE 4]
Étape quatre : teste-le. Ouvre une nouvelle conversation et demande normalement : écris le script d'une vidéo sur tel sujet. Tu n'as pas besoin de citer le Skill. Claude le reconnaît, l'ouvre, et suit ta structure.

[ASTUCE]
Et si tu ne veux rien écrire toi-même : dans le menu Ajouter, choisis Créer avec Claude. Tu décris ce que tu veux, et Claude écrit le Skill pour toi.

[ERREURS]
Deux erreurs fréquentes. Un : le Skill ne se déclenche jamais. C'est presque toujours la description, trop vague. Écris quand l'utiliser, avec les mots que tu tapes vraiment. Deux : l'import refuse ton fichier. Vérifie que les trois tirets du début et de la fin du bloc nom-description sont bien là.

[RÉSULTAT ET CADEAU]
Résultat : dix minutes, zéro euro de plus, et un assistant qui écrit à ta façon, à chaque fois. Mon Skill scénariste est gratuit dans la description, avec le fichier prêt à importer. Prochaine vidéo : je te montre les vrais chiffres de la chaîne après une semaine. Abonne-toi.

## À enregistrer (claude.ai, compte d'Alae, Chrome, barre latérale masquée)
1. Paramètres > Capacités > « Créer et modifier des fichiers » (déjà activé).
2. Plug-ins > Skills > Ajouter > Importer un plug-in > SKILL.md > Importer (l'interface accepte .skill, .zip ou .md, vérifié le 20/11).
3. Nouvelle conversation : « Écris le script d'une vidéo sur [sujet] » → Claude utilise le Skill.
Étape 2 (Bloc-notes) : recréée en animation. Enregistrement via rec.html (capture d'onglet Chrome).
