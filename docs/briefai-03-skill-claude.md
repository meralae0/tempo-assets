# BriefAI #3 — « Crée ton propre Skill Claude en 10 minutes (sans coder) »

Format tuto : vrai enregistrement de claude.ai (Chrome, Xbox Game Bar Win+Alt+R) + habillage Remotion (compteur d'étapes, zooms, curseur, bulles).
Une vidéo en français + piste audio anglaise. Cadeau : skills/scenariste-youtube (SKILL.md + ZIP) sur GitHub.
Sources : support.claude.com « Use skills in Claude » et « How to create custom skills » (consultées le 20/11/2026).

## Script FR (≈ 150 mots/min)
[RÉSULTAT]
Regarde. Je tape une seule phrase : « écris le script de ma prochaine vidéo ». Et Claude me sort un script complet, dans mon format exact : l'accroche, les étapes, les erreurs, le cadeau. Ce n'est pas un prompt que je recopie à chaque fois. C'est un Skill. Et dans dix minutes, tu auras le tien.

[C'EST QUOI]
Un Skill, c'est une fiche d'instructions que Claude garde en mémoire. Quand ta demande correspond, il l'ouvre tout seul et suit tes règles. Ça marche aussi avec le compte gratuit.

[ÉTAPE 1]
Étape un : activer l'option. Va dans Paramètres, puis Capacités. Active « Exécution de code et création de fichiers ». Si c'est déjà bleu, c'est bon.

[ÉTAPE 2]
Étape deux : crée un dossier sur ton ordinateur. Donne-lui le nom de ton Skill, en minuscules, avec des tirets. Par exemple : scénariste tiret youtube.

[ÉTAPE 3]
Étape trois : dans ce dossier, crée un fichier texte qui s'appelle SKILL point md. Il a trois blocs. Le nom, le même que le dossier. La description : c'est la phrase que Claude lit pour savoir quand utiliser ton Skill. Deux cents caractères maximum. Et en dessous, tes instructions, comme si tu briefais un assistant.

[ÉTAPE 4]
Étape quatre : compresse le dossier. Clic droit, Envoyer vers, Dossier compressé. Tu obtiens un fichier ZIP.

[ÉTAPE 5]
Étape cinq : importe-le. Dans Claude, va dans Personnaliser, puis Skills. Clique sur le plus, Créer un skill, puis Importer un skill. Choisis ton ZIP. Ton Skill apparaît dans la liste, activé.

[ÉTAPE 6]
Étape six : teste-le. Ouvre une nouvelle conversation et demande normalement : écris le script d'une vidéo sur tel sujet. Tu n'as pas besoin de citer le Skill. Claude le reconnaît, l'ouvre, et suit ta structure.

[ERREURS]
Deux erreurs fréquentes. Un : le Skill ne se déclenche jamais. C'est presque toujours la description, trop vague. Écris quand l'utiliser, avec les mots que tu tapes vraiment. Deux : l'import refuse ton ZIP. Vérifie que le nom du dossier est exactement le même que le nom dans le fichier.

[RÉSULTAT ET CADEAU]
Résultat : dix minutes, zéro euro de plus, et un assistant qui écrit à ta façon, à chaque fois. Mon Skill scénariste est gratuit dans la description, avec le fichier prêt à importer. Prochaine vidéo : je te montre les vrais chiffres de la chaîne après une semaine. Abonne-toi.

## À enregistrer (claude.ai, compte d'Alae, Chrome)
1. Paramètres > Capacités > option « Exécution de code et création de fichiers ».
2. Personnaliser > Skills > + > Créer un skill > Importer un skill > choix du ZIP > Skill visible et activé.
3. Nouvelle conversation : « Écris le script d'une vidéo sur [sujet] » → Claude utilise le Skill.
Étapes 2 à 4 (dossier, fichier, ZIP) : recréées en animation (Game Bar ne filme pas l'Explorateur Windows).
