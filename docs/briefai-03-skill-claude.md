# BriefAI #3 — « Crée ton propre Skill Claude en 2 minutes (sans coder, sans fichier) »

Format tuto : vraies captures de claude.ai (compte d'Alae, 20/11/2026, barre latérale masquée) animées dans Remotion (compteur d'étapes, zooms, curseur, clics).
Une vidéo en français + piste audio anglaise. Cadeau : la demande exacte à copier + le fichier SKILL.md (skills/scenariste-youtube sur GitHub).
Interface vérifiée le 20/11/2026 : Paramètres › Capacités › « Créer et modifier des fichiers » ; Plug-ins › Skills › Ajouter › « Créer avec Claude » ou « Importer un plug-in » (.skill, .zip ou .md).
Captures : episodes/briefai-03/caps/ (01 à 19). À flouter : le prénom dans la carte (10, 11) et le message d'accueil (13).

## Script FR (≈ 150 mots/min)
[RÉSULTAT]
Regarde. Je demande juste : « écris le script d'une vidéo sur un logo gratuit avec l'IA ». Claude charge mon Skill, vérifie les boutons sur le site, et me rend un script complet : les étapes, les erreurs, les sources. Dans cinq minutes, tu auras le même. Sans coder, et sans fichier.

[C'EST QUOI]
Un Skill, c'est une fiche d'instructions que Claude garde. Quand ta demande correspond, il l'ouvre tout seul et suit tes règles. Tu l'écris une fois, il sert à chaque fois.

[ÉTAPE 1]
Étape un : vérifie l'option. Ouvre les Paramètres, puis Capacités. « Créer et modifier des fichiers » doit être activé. Les Skills en ont besoin.

[ÉTAPE 2]
Étape deux : ouvre Plug-ins, puis l'onglet Skills. Clique sur Ajouter, puis sur « Créer avec Claude ». Une conversation s'ouvre, avec une phrase déjà écrite.

[ÉTAPE 3]
Étape trois : remplace-la par ta demande. Dis ce que le Skill doit faire, et comment. Moi, je veux un scénariste : une accroche de cinq secondes, des étapes avec le bouton exact, deux erreurs fréquentes, puis le temps et le coût. Phrases courtes, et une source pour chaque chiffre. Envoie.

[ÉTAPE 4]
Étape quatre : Claude écrit le Skill et te montre une carte. Ouvre « Contenu » pour le relire. Si c'est bon, clique sur Enregistrer. Le Skill apparaît dans tes Plug-ins, avec l'étiquette Nouveau.

[ÉTAPE 5]
Étape cinq : teste-le. Ouvre une nouvelle conversation et demande normalement. Pas besoin de citer le Skill. Regarde : « Chargeant une compétence ». Claude l'a trouvé tout seul.

[ERREURS]
Deux erreurs fréquentes. Un : le Skill ne se déclenche pas. C'est presque toujours la description, trop vague. Demande à Claude de la réécrire avec les mots que tu tapes vraiment. Deux : tu enregistres sans relire. Ouvre toujours « Contenu » : c'est là que tu vois s'il a bien compris tes règles.

[RÉSULTAT ET CADEAU]
Résultat : cinq minutes, zéro euro de plus, et un assistant qui écrit à ta façon, à chaque fois. Ma demande exacte et mon fichier Skill sont gratuits dans la description. Si tu as déjà un fichier SKILL point md, le menu Ajouter permet aussi de l'importer. Prochaine vidéo : les vrais chiffres de la chaîne après une semaine. Abonne-toi.
