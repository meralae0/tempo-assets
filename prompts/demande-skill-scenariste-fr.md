# Demande exacte utilisée dans la vidéo (BriefAI #3)
À coller dans Claude : Plug-ins › Skills › Ajouter › « Créer avec Claude ».

Crée-moi un Skill « scénariste YouTube ». Quand je demande un script de vidéo, il écrit un tuto prêt à lire en voix off : une accroche de 5 secondes qui montre le résultat, les étapes avec le bouton exact à cliquer, 2 erreurs fréquentes et leur solution, puis le résultat avec le temps et le coût. Phrases courtes, tutoiement, 150 mots par minute. Chaque chiffre doit avoir une source.

Tu préfères importer un fichier ? skills/scenariste-youtube/SKILL.md (Plug-ins › Skills › Ajouter › Importer un plug-in, fichier .md accepté).
